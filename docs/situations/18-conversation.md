# Situation 18 : Comprendre une conversation

Univers : Échanges quotidiens.

## Contexte de la scène

Des annonces et des échanges courts que l'on entend autour de soi. Scène fictive mais réaliste, jouée comme un jeu de rôle oral.

## Objectif de communication

À la fin de la situation, Sondes sait saisir l'essentiel d'une annonce ou d'une conversation courte et dire l'information principale.

## Personnages

Une voix dans une annonce, ou deux adultes qui parlent entre eux.

## Réponses possibles de Sondes

La reconnaissance vocale accepte ces variantes (sans accents ni ponctuation) :

- Demain, il va pleuvoir : demain il va pleuvoir ; il va pleuvoir ; pluie ; demain pluie
- Toutes les dix minutes : toutes les dix minutes ; dix minutes ; toutes les 10 minutes
- À sept heures : a sept heures ; sept heures ; a 7 heures
- Mardi, dix-huit heures : mardi dix huit heures ; mardi 18 heures ; mardi ; dix huit heures
- Le médecin est absent : le medecin est absent ; absent ; medecin absent
- Fermé le dimanche : ferme le dimanche ; le dimanche ; dimanche ; ferme
- Jeudi, avant midi : jeudi avant midi ; jeudi ; avant midi

## Dialogues enregistrés

### Dialogue principal (séance conversation-4)

- Interlocuteur : Excusez-moi, le bus pour le centre-ville ? Il passe toutes les dix minutes, mais le dimanche, il passe seulement toutes les vingt minutes.
- Sondes (au choix) : Répétez, s'il vous plaît / Plus lentement, s'il vous plaît
- Interlocuteur : Le bus passe toutes les dix minutes.
- Sondes : Toutes les dix minutes
- Interlocuteur : La boulangerie ferme à sept heures.
- Sondes : À sept heures
- Interlocuteur : Le magasin est fermé le dimanche.
- Sondes : Fermé le dimanche

### Variante avec imprévu (séance conversation-5)

- Interlocuteur : Allô ? Oui, le docteur n'est pas là cette semaine, mais le docteur Martin le remplace, du lundi au jeudi, de neuf heures à midi.
- Sondes (au choix) : Répétez, s'il vous plaît / Plus lentement, s'il vous plaît / Je ne comprends pas
- Interlocuteur : Le médecin est absent cette semaine.
- Sondes : Le médecin est absent
- Interlocuteur : Il y a une réunion mardi à dix-huit heures.
- Sondes : Mardi, dix-huit heures
- Interlocuteur : Votre colis arrive jeudi, avant midi.
- Sondes : Jeudi, avant midi

## Imprévus

Réplique longue ou rapide, hors du niveau de Sondes. Elle utilise alors les phrases de secours (« répétez, s'il vous plaît », « plus lentement, s'il vous plaît », « je ne comprends pas »), apprises dans la situation 1.

- « Excusez-moi, le bus pour le centre-ville ? Il passe toutes les dix minutes, mais le dimanche, il passe seulement toutes les vingt minutes. »
- « Allô ? Oui, le docteur n'est pas là cette semaine, mais le docteur Martin le remplace, du lundi au jeudi, de neuf heures à midi. »

## Mission facultative dans la vie réelle

Écouter une annonce ou une conversation du quotidien et repérer une information (heure, jour, lieu).

Le lendemain, l'application demande à Sondes, avec trois images (facile, moyen, difficile), comment cela s'est passé. Elle choisit d'en parler ou non.

## Suivi
