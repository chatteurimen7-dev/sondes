# Situation 7 : Demander un petit service

Univers : Maison et voisinage.

## Contexte de la scène

Un petit service entre voisins. Scène fictive mais réaliste, jouée comme un jeu de rôle oral.

## Objectif de communication

À la fin de la situation, Sondes sait demander de l'aide, répondre à une demande et remercier.

## Personnages

Un voisin ou une voisine adulte, qui demande ou rend un petit service.

## Phrases françaises utiles et explication en derja

Chaque ligne est un élément à écouter, comprendre, répéter, puis dire. La colonne de droite est l'intention de l'explication en derja : la locutrice tunisienne la formule à sa façon et l'enregistre (identifiant `aeb/sens-<élément>`).

| Qu'est-ce que je peux faire pour vous ? | Pouvez-vous porter ce sac, s'il vous plaît ? | Expliquer en quelques mots ce que veut dire « Qu'est-ce que je peux faire pour vous ? » : le voisin demande ce dont vous avez besoin. |

| Vous pouvez m'aider avec ce sac ? | Oui, bien sûr | Expliquer en quelques mots ce que veut dire « Vous pouvez m'aider avec ce sac ? » : un voisin vous demande de l'aider avec un sac lourd. |

## Réponses possibles de Sondes

La reconnaissance vocale accepte ces variantes (sans accents ni ponctuation) :

- Oui, vous pouvez m'aider, s'il vous plaît ? : oui vous pouvez m aider s il vous plait ; vous pouvez m aider ; pouvez vous m aider ; oui ; aidez moi
- Pouvez-vous porter ce sac, s'il vous plaît ? : pouvez vous porter ce sac s il vous plait ; porter ce sac ; ce sac ; pouvez vous porter ce sac ; vous pouvez porter ce sac
- Merci beaucoup : merci beaucoup ; merci
- Oui, bien sûr : oui bien sur ; bien sur ; oui
- Oui, bien sûr : oui bien sur ; bien sur ; oui
- Oui, voilà : oui voila ; voila ; non desolee ; non
- Ce n'est pas grave, merci : ce n est pas grave merci ; pas grave ; ce n est pas grave ; merci
- Ce n'est pas grave : ce n est pas grave ; pas grave
- Je vous en prie : je vous en prie ; de rien

## Dialogues enregistrés

### Dialogue principal (séance service-4)

- Interlocuteur : Bonjour, vous avez un problème ?
- Sondes : Oui, vous pouvez m'aider, s'il vous plaît ?
- Interlocuteur : Qu'est-ce que je peux faire pour vous ?
- Sondes : Pouvez-vous porter ce sac, s'il vous plaît ?
- Interlocuteur : Voilà, c'est fait !
- Sondes : Merci beaucoup

### Variante avec imprévu (séance service-5)

- Interlocuteur : Vous pouvez tenir la porte, s'il vous plaît ?
- Sondes : Oui, bien sûr
- Interlocuteur : Merci beaucoup !
- Sondes : Je vous en prie
- Interlocuteur : Ah, attendez, vous pouvez aussi m'aider à monter ce carton au deuxième étage ? Je n'arrive pas à le porter toute seule.
- Sondes (au choix) : Répétez, s'il vous plaît / Plus lentement, s'il vous plaît / Je ne comprends pas
- Interlocuteur : Vous pouvez m'aider avec ce sac ?
- Sondes : Oui, bien sûr
- Interlocuteur : Voilà, c'est fait !
- Sondes : Merci beaucoup

## Imprévus

Réplique longue ou rapide, hors du niveau de Sondes. Elle utilise alors les phrases de secours (« répétez, s'il vous plaît », « plus lentement, s'il vous plaît », « je ne comprends pas »), apprises dans la situation 1.

- « Ah, attendez, vous pouvez aussi m'aider à monter ce carton au deuxième étage ? Je n'arrive pas à le porter toute seule. »

## Mission facultative dans la vie réelle

Demander ou rendre un petit service simple à un voisin ou à une voisine.

Le lendemain, l'application demande à Sondes, avec trois images (facile, moyen, difficile), comment cela s'est passé. Elle choisit d'en parler ou non.
