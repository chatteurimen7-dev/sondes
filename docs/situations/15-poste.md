# Situation 15 : Aller à la poste

Univers : Services et démarches.

## Contexte de la scène

Un bureau de poste. Scène fictive mais réaliste, jouée comme un jeu de rôle oral.

## Objectif de communication

À la fin de la situation, Sondes sait envoyer une lettre ou un colis, acheter un timbre et payer.

## Personnages

Une employée de la poste, derrière le guichet.

## Réponses possibles de Sondes

La reconnaissance vocale accepte ces variantes (sans accents ni ponctuation) :

- Je voudrais un timbre, s'il vous plaît : je voudrais un timbre s il vous plait ; je voudrais un timbre ; un timbre ; timbre
- Je voudrais envoyer cette lettre : je voudrais envoyer cette lettre ; envoyer cette lettre ; cette lettre ; je voudrais envoyer une lettre
- Je voudrais envoyer ce colis : je voudrais envoyer ce colis ; envoyer ce colis ; ce colis ; je voudrais envoyer un colis
- Pour la Tunisie : pour la tunisie ; la tunisie ; tunisie ; pour la france ; la france
- D'accord : d accord ; oui ; ok
- D'accord, voilà : d accord voila ; d accord ; voila
- Oui, s'il vous plaît : oui s il vous plait ; oui ; non merci ; non
- D'accord, merci : d accord merci ; d accord ; merci

## Dialogues enregistrés

- Interlocuteur : Bonjour !
- Sondes : Bonjour

- Sondes : Pour la Tunisie

- Sondes : D'accord

### Variante avec imprévu (séance poste-5)

- Interlocuteur : Bonjour !
- Sondes : Bonjour
- Sondes : Je voudrais envoyer cette lettre
- Interlocuteur : Pour une lettre simple, vous pouvez directement la mettre dans la boîte jaune dehors, mais il faut un timbre, et ici, je peux vous en vendre un, ou un carnet de dix.
- Sondes (au choix) : Répétez, s'il vous plaît / Plus lentement, s'il vous plaît / Je ne comprends pas
- Sondes : Je voudrais un timbre, s'il vous plaît
- Interlocuteur : Ça fait dix-huit euros.
- Sondes : D'accord, voilà
- Interlocuteur : Vous voulez un suivi ?
- Sondes : Oui, s'il vous plaît

## Imprévus

Réplique longue ou rapide, hors du niveau de Sondes. Elle utilise alors les phrases de secours (« répétez, s'il vous plaît », « plus lentement, s'il vous plaît », « je ne comprends pas »), apprises dans la situation 1.

- « Pour une lettre simple, vous pouvez directement la mettre dans la boîte jaune dehors, mais il faut un timbre, et ici, je peux vous en vendre un, ou un carnet de dix. »

## Mission facultative dans la vie réelle

Aller à la poste pour acheter un timbre ou envoyer une lettre.

Le lendemain, l'application demande à Sondes, avec trois images (facile, moyen, difficile), comment cela s'est passé. Elle choisit d'en parler ou non.

## Suivi

- Durée indicative : 60 minutes, soit 5 séances d'environ 12 minutes.
- Temps réel, séances faites, compétences travaillées, progression et éléments à revoir : tableau de bord de l'espace accompagnante.
- Éléments à revoir : l'application propose en début de séance les phrases dont la révision est due.
- Enregistrements nécessaires : environ 20 messages en derja et 17 phrases en français (voir `docs/fiche-enregistrement.csv`).
