# Situation 3 : Demander un prix

Univers : Courses.

## Contexte de la scène

Les prix dans un magasin. Scène fictive mais réaliste, jouée comme un jeu de rôle oral.

## Objectif de communication

À la fin de la situation, Sondes sait demander un prix et comprendre un prix annoncé, en euros et en centimes.

## Personnages

Un vendeur ou une vendeuse dans un magasin ou au marché.

## Réponses possibles de Sondes

La reconnaissance vocale accepte ces variantes (sans accents ni ponctuation) :

- Combien ça coûte ? : combien ca coute ; combien ca fait ; c est combien ; combien
- Un euro : un euro ; 1 euro ; 1
- Deux euros : deux euros ; 2 euros ; 2
- Trois euros : trois euros ; 3 euros ; 3
- Cinq euros : cinq euros ; 5 euros ; 5
- Dix euros : dix euros ; 10 euros ; 10
- Un euro cinquante : un euro cinquante ; 1 euro 50 ; 1 50 ; un euro 50 ; un cinquante
- C'est trop cher : c est trop cher ; trop cher ; c est cher
- D'accord, merci : d accord merci ; d accord ; merci ; ah d accord
- Oui, je le prends : oui je le prends ; oui ; je le prends ; non merci ; non

## Dialogues enregistrés

### Dialogue principal (séance prix-5)

- Interlocuteur : Bonjour !
- Sondes : Bonjour
- Interlocuteur : Bonjour, je peux vous aider ?
- Sondes : Combien ça coûte ?
- Interlocuteur : Ça fait trois euros.
- Sondes : Trois euros
- Interlocuteur : Vous le prenez ?
- Sondes : Oui, je le prends
- Interlocuteur : Au revoir !
- Sondes : Au revoir

### Variante avec imprévu (séance prix-6)

- Interlocuteur : Bonjour !
- Sondes : Bonjour
- Sondes : Combien ça coûte ?
- Interlocuteur : Alors, ça, c'est trois euros quatre-vingt-dix, mais si vous en prenez deux, je vous fais un prix : cinq euros.
- Sondes (au choix) : Répétez, s'il vous plaît / Plus lentement, s'il vous plaît / Je ne comprends pas
- Interlocuteur : Ça fait cinq euros.
- Sondes : Cinq euros
- Interlocuteur : Vous le prenez ?
- Sondes : Oui, je le prends
- Interlocuteur : Merci !
- Sondes : Merci

## Imprévus

Réplique longue ou rapide, hors du niveau de Sondes. Elle utilise alors les phrases de secours (« répétez, s'il vous plaît », « plus lentement, s'il vous plaît », « je ne comprends pas »), apprises dans la situation 1.

- « Alors, ça, c'est trois euros quatre-vingt-dix, mais si vous en prenez deux, je vous fais un prix : cinq euros. »

## Mission facultative dans la vie réelle

Demander le prix d'un article dans un magasin ou au marché.

Le lendemain, l'application demande à Sondes, avec trois images (facile, moyen, difficile), comment cela s'est passé. Elle choisit d'en parler ou non.

## Suivi

- Durée indicative : 72 minutes, soit 6 séances d'environ 12 minutes.

- Éléments à revoir : l'application propose en début de séance les phrases dont la révision est due.
